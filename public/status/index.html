3Your Anthropic (Claude) key in AWS Secrets ManagerWaiting on your server.

An API key is how your own server talks to an AI provider, billed to your own account there, the same way a password lets you talk to a website. You hold your own keys instead of Acorn holding them for you, so your spend and your data stay under your own provider account, never ours. That is also why the key goes into your own AWS Secrets Manager instead of a form on this page: Secrets Manager is a vault inside your own AWS account, built to hold exactly this kind of value, and it means the plaintext key is never typed into buyacorn.com at all. One key runs your Acorn: your Anthropic (Claude) key. Open your own AWS Secrets Manager first, then add it: get the key from Anthropic's own console, then put it in Secrets Manager under its exact secret name. Your server read-tests it and this phase turns green. Grok and Gemini keys are optional extras, waiting for you at the bottom of this page once your Acorn is live.

Secret
AWS Secrets Manager's name for one stored value. Your Claude key is a secret; so is the value you paste in for each provider.
Plaintext value
The key itself, typed or pasted in as plain text, with no extra formatting. Secrets Manager encrypts it for you once you save it.
API key, not a subscription
An API key is different from a claude.ai/ChatGPT-style consumer plan. A consumer subscription lets a person chat in a browser; an API key lets your own server call the model directly, billed by usage to your own provider account. Your claude.ai plan will not work here. Any email works to sign up for the provider console and create one.

Sign in to your own AWS account and open AWS Secrets Manager. Check the box once it is open.

You are on the wrong page if you see the word DocumentDB anywhere. DocumentDB is a different AWS service, a database, and has nothing to do with storing your key. If you searched for Secrets Manager and landed there instead, use the link above rather than the AWS search bar, or search the exact term "Secrets Manager".

When you click Store a new secret for any key, here or in the optional group at the bottom of this page, choose Other type of secret first, before anything else on that screen. That one click keeps the form asking for a plain key and value instead of database credentials.

After you paste the key and name the secret, the wizard shows a few more screens. Same answer every time, for every key you add:

  1. Encryption key: leave the default aws/secretsmanager selected.
  2. Replicate secret: leave unchecked. You do not need this.
  3. Automatic rotation: leave off. You can turn this on later if you want it.
  4. Tags: skip. Optional, and not needed for your Acorn to work.
  5. Review, then click Store.

    "event_subscriptions": {

        "app_mention",
        "message.channels",
        "message.groups",
        "file_shared"
      ]
    },
    "org_deploy_enabled": false,
    "socket_mode_enabled": true,

Slack setup, click by click

Your Acorn runs as two Slack apps in your own workspace: the responder (answers you in #acorn) and the notetaker (captures what you choose to share). You create both, you install both, and every token lands in your own AWS Secrets Manager. Nothing here passes through us. The two app steps above carry each manifest inline; this section keeps the same manifests together for reference.

  1. Open api.slack.com/apps and sign in to the workspace where your team works.
  2. Click Create New App, choose From a manifest, pick your workspace, and paste the responder manifest below. Click through to create it.
  3. Repeat for the notetaker: Create New App, From a manifest, same workspace, notetaker manifest below.
  4. On each app's page, click Install to Workspace and approve. Slack shows you what each app can see before you approve; that screen is Slack's own security boundary, and only you can click it. After installing, copy each app's Bot User OAuth Token from OAuth & Permissions.
  5. On each app's Basic Information page, under App-Level Tokens, click Generate Token and Scopes, add the connections:write scope, and generate. Copy each value.
  6. You now hold four values: two bot tokens and two app-level tokens. Paste them into your own AWS Secrets Manager as your setup guide shows. Your box read-tests them and the checks above turn green on their own.
